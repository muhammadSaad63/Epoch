# Epoch
A Git clone made in CPP :)


---


Libraries Required:
* File & Folders Manipulation: std::filesystem
* CLI Formatting: rang
* Diff Engine: dtl
* Indexing: nlohmann/json
* Hashing: stbrumme/hash-library
* Argument Parsing: CLI11
* Compression: miniz
* Filing: fstream
- Date/Time: chrono
- iostream
- string
- vector
